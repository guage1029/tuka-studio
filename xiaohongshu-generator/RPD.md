# tuka.guage.chat 产品需求

更新：2026-10-21。本文件替代旧版「现状还原」要求，以公网图卡工具计划为准。

## 用户与目标
面向持有国产模型开放平台 API Key 的内容创作者。用真实模板图卡展示能力，观察生成与下载次数，再决定后续迭代。无需注册、自带国产模型 Key；不增加账号、历史、草稿持久化、支付、后台或通用模型代理。

## 页面与流程
- `/`：价值介绍与真实图卡组合、首批 12 款样式、展开全部 46 款、三步说明、模型与隐私说明、开始使用。样例可放大；使用样式进入 `/app?style=…`。
- `/app`：内存配置（选择国产厂商 → 输入 Key → 刷新模型列表 → 从下拉框选择模型），粘贴正文/Markdown → 选样式 → 生成文案 → 编辑标题/标签/要点/配图、单页重生成 → 渲染 → 单张或 ZIP 下载。配置可折叠；换模板不调用模型。
- 输入就地校验；失败保留输入、编辑和已有结果。输入候选配图不按数量拦截；无论文章与图片多少，输出最多 9 张图卡。模型根据图片说明、位置和正文上下文选择每张卡的最佳相关配图，多余不使用；选中图无法获取则跳过并提示，保留文案，支持编辑补图。鉴权、余额、参数拒绝分别提示。异步响应不得覆盖后续编辑；删除再添加要点不得出现重复标识。
- 第一期固定 DeepSeek、MiniMax、Kimi、智谱 GLM、豆包国内接口；地址/协议由后端确定，不支持海外厂商或自定义地址。OpenAI Chat Completions、Anthropic Messages 仅是兼容协议，无厂商自动回退。内容发送至所选厂商，费用与第三方保留策略由该厂商决定。
- DeepSeek/Kimi 实时获取模型；其余三家使用有日期和来源说明的官方预置目录，Key/余额/权限在生成时校验。刷新不调用生成接口或增加生成统计。详细范围见 `PROVIDERS.md`。
- 兼容模型数字字符串图号和缺省可选字段；非法图号不阻断文案。JSON 或卡片字段、字数、页数不合规时，在原总时限内最多自动纠正一次（可能增加一次模型费用），仍失败则保留输入并区分错误；不得靠直接截断事实或放宽渲染校验掩盖问题。

## 数据边界
服务器临时转发请求并在内存渲染，不持久化 Key、正文、配图、模型结果和成图。浏览器只在当前页面内存保留工作数据，刷新即丢失。禁用内容日志、追踪、请求/响应缓存、共享产物下载。历史本地文件不自动删除，公网服务不读取或暴露它们。

唯一持久化例外为匿名汇总计数：日期、受控事件类型、模板编号、受控错误分类、次数。保存 90 天，不保存原始事件、用户标识、完整 IP、API 地址、内容或 Key。事件：首页访问、进入工具、样例查看、模板选择、生成开始、生成成功、生成失败、下载点击。生成指文案整理请求（含单页重生成），渲染不重复记账。服务端记录生成结果，前端只报告交互。

统计只是次数，不能解释为人数、留存或严格转化漏斗；下载点击不代表已保存文件。仅提供服务器本地只读统计命令，无公开查询接口。

## 验收
- 46 个独立 HTML 模板与内嵌 CSS，保留来源许可；示例由同一渲染器生成，缩略图匹配展示尺寸、保留宽高、延迟加载。
- 浅色中性画廊、深色正文、克制强调色；自托管 Inter/Noto Sans SC、保留许可证与系统回退，线性 SVG 图标。
- 桌面双栏、小屏顺序布局；375/768/1024/1440px 无横向溢出。正文对比度 ≥4.5:1、键盘可操作、焦点可见、主要触控目标 ≥44px。遵循减少动态效果，无自动轮播。
- 两协议离线测试覆盖鉴权、超时、截断、空响应、非法 JSON；请求隔离、输入转义、图片校验、SSRF/重定向阻断、并发/频率/大小/超时限制。
- 全模板渲染、长标题/多要点/配图、深链、编辑/重生成/渲染/下载及统计并发验证；工程、视觉、未验证事项分别记录。
- 提供 HTTPS 反代与内存临时目录部署配置；生产发布、证书和 DNS 另行授权。
