## 📋 1. 产品概述

### 1.1 产品定义
**RednoteGen** 是一款基于 AI 的智能图文卡片生成工具，专为小红书内容创作者设计。用户只需粘贴长文内容（支持 Markdown 格式），系统即可自动完成内容分析、智能拆分、风格渲染和图片生成，一键输出精美的图文卡片。

### 1.2 核心价值主张
| 痛点 | 解决方案 |
|------|----------|
| 长文排版耗时费力 | AI 智能分析，自动拆分为6-9张卡片 |
| 设计能力不足 | 提供13种精美模板，一键切换风格 |
| 图文搭配困难 | Markdown 图片自动提取，AI 智能分配 |
| 违规词不自知 | 内置敏感词检测，发布前一键筛查 |

### 1.3 目标用户
- 小红书内容创作者
- 自媒体运营人员
- 知识博主 / 图文创作者
- 需要快速产出精美图卡的任何人

## 🚀 2. 核心功能

### 2.1 AI 智能内容分析
- **自动决策卡片数量**: AI 根据文章信息密度、逻辑结构自主决定生成 5-8 张内容卡片（总计 6-9 张含封面）
- **智能要点提炼**: 保留核心观点、关键数据、重要案例，每个要点控制在 35 字以内
- **封面生成**: 自动生成吸睛标题（≤10字）、副标题和3-5个相关标签
- **图片智能分配**: 支持 Markdown 图片语法，AI 根据内容相关度智能分配到对应卡片

### 2.2 多风格模板系统
| 序号 | 风格名称 | 特点 | 适用场景 |
|------|----------|------|----------|
| 1 | 小红书 | 紫粉渐变，经典风格 | 通用内容 |
| 2 | 苹果极简 | 纯黑白灰，高级感 | 干货知识、工具推荐 |
| 3 | 新粗野 | 高饱和糖果色，粗边框硬阴影 | 创意灵感、潮流话题 |
| 4 | Capsule | 终端代码风格，霓虹绿 | 技术教程、编程分享 |
| 5 | 知识胶囊 | 蓝紫渐变风 | AI、科技、硬核内容 |
| 6 | Notion/备忘录 | 苹果 Notes 风格 | 学习笔记、待办清单 |
| 7 | 孟菲斯 | 复古波普风 | 年轻话题、潮流文化 |
| 8 | 新中式 | 国潮水墨风 | 传统文化、情感语录 |
| 9 | 拍立得 | 胶片复古风 | 生活记录、文艺内容 |
| 10 | 流光卡片 | 动态渐变光晕 | 科技产品、高端内容 |
| 11 | 手账风 | 纸张纹理贴纸 | 日常记录、学习笔记 |
| 12 | 杂志风 | 黑白高级排版 | 时尚内容、深度文章 |
| 13 | INS风 | Instagram 渐变 | 生活方式、潮流分享 |

### 2.3 违禁词检测系统
- **内置敏感词库**: 8大分类，200+违规词汇
- **一键扫描**: 发布前全文扫描，违规词高亮标红
- **分类统计**: 按类别显示检测结果

### 2.4 图片处理规则

| 场景 | 处理方式 |
|------|----------|
| GIF 图片 | 自动跳过，不参与分配 |
| 图片 URL 无法访问 | 静默跳过 |
| 图片 > 卡片数量 | AI 丢弃相关度低的图片 |
| 图片 < 卡片数量 | 只为相关度最高的卡片分配 |
| 图片 = 卡片数量 | 按相关度一一分配 |

**支持格式**: PNG、JPG、JPEG、WebP  
**图片尺寸**: 自适应高度，最大不超过卡片 40%  
**图片来源**: Markdown URL / 粘贴 / 拖拽 / 本地上传

## 📡 4. API 接口设计

### 4.1 接口列表

| 接口 | 方法 | 功能描述 |
|------|------|----------|
| `/` | GET | 主页（Web 界面） |
| `/preview` | POST | 预览模式：AI 分析内容，返回结构化数据 |
| `/render` | POST | 渲染模式：使用已有 JSON 渲染指定风格图片 |
| `/generate` | POST | 一键生成：AI 分析 + 渲染图片 |
| `/regenerate-slide` | POST | 重新生成单张卡片内容 |
| `/regenerate-style` | POST | 切换风格（不重新调用 AI） |
| `/check-sensitive` | POST | 违禁词检测 |
| `/upload-image` | POST | 上传图片 (Base64/File) |
| `/validate-image-url` | POST | 验证图片 URL 可访问性 |
| `/download/<filename>` | GET | 下载单张图片 |
| `/download-all` | GET | 下载所有图片 (ZIP) |
| `/get-sensitive-categories` | GET | 获取敏感词分类信息 |

### 4.2 核心 API 数据结构

**AI 输出 JSON 结构**:
```json
{
  "cover_title": "封面大标题",
  "cover_subtitle": "封面副标题",
  "cover_tags": ["标签1", "标签2", "标签3"],
  "cover_image": "https://example.com/cover.png",
  "slides": [
    {
      "title": "第1张幻灯片标题",
      "content": ["要点1", "要点2", "要点3"],
      "image": "https://example.com/slide1.png"
    },
    {
      "title": "第2张幻灯片标题",
      "content": ["要点1", "要点2", "要点3"],
      "image": null
    }
  ]
}
```

## 🔄 6. 用户工作流

```
┌──────────────────────────────────────────────────────────────────┐
│  1️⃣ 输入阶段                                                     │
│     用户粘贴内容（支持纯文本 / Markdown + 图片）                     │
│     建议长度：500-5000 字                                          │
└──────────────────────────────────────────────────────────────────┘
                                  ↓
┌──────────────────────────────────────────────────────────────────┐
│  2️⃣ 预处理阶段                                                    │
│     - 解析 Markdown 文本                                          │
│     - 提取图片 URL 列表                                            │
│     - 过滤 GIF / 验证 URL 可访问性                                  │
└──────────────────────────────────────────────────────────────────┘
                                  ↓
┌──────────────────────────────────────────────────────────────────┐
│  3️⃣ AI 分析阶段                                                   │
│     - 分析内容结构和信息密度                                        │
│     - 自主决定卡片数量（5-8 张内容页）                              │
│     - 生成标题、副标题、标签、要点                                   │
│     - 智能分配图片到对应卡片                                        │
└──────────────────────────────────────────────────────────────────┘
                                  ↓
┌──────────────────────────────────────────────────────────────────┐
│  4️⃣ 预览/编辑阶段                                                 │
│     - 实时预览所有卡片                                             │
│     - 编辑文字内容（标题、副标题、标签、要点）                       │
│     - 调整图片分配（删除、替换、移动）                              │
│     - 违禁词检测                                                   │
└──────────────────────────────────────────────────────────────────┘
                                  ↓
┌──────────────────────────────────────────────────────────────────┐
│  5️⃣ 风格切换（可选）                                               │
│     - 无需重新调用 AI                                              │
│     - 秒速切换 13 种风格                                           │
└──────────────────────────────────────────────────────────────────┘
                                  ↓
┌──────────────────────────────────────────────────────────────────┐
│  6️⃣ 生成/导出阶段                                                 │
│     - Playwright 渲染截图                                         │
│     - 输出标准 3:4 比例图片（1242x1660px）                          │
│     - 单张下载 / 批量下载 (ZIP)                                    │
└──────────────────────────────────────────────────────────────────┘
```

## ⚙️ 7. 配置项说明

### 7.1 API 配置

```python
# config.py

GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
MODEL_NAME = "models/gemini-2.5-flash-lite"

OPENAI_BASE_URL = "https://api.openai.com/v1"
OPENAI_API_KEY = "sk-your-openai-key"
MODEL_NAME = "gpt-4o"

# 方式三：DeepSeek
OPENAI_BASE_URL = "https://api.deepseek.com"
OPENAI_API_KEY = "sk-your-deepseek-key"
MODEL_NAME = "deepseek-chat"
```
